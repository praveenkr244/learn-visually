How arrays live in memory

Most array questions come down to two facts: the array is an object, and variables hold its address.

Q1What is an array in Java?

An array is an object that holds a fixed number of values of one type in a single block of memory. Its size is set when it is created and can never change. It carries a length field, and it lives on the heap even when the elements are primitives.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] scores = {90, 72, 85};         // literal: size fixed at 3
        double[] prices = new double[4];     // all zeros
        prices[1] = 9.99;

        System.out.println(scores.length);               // 3: a field, not a method
        System.out.println(Arrays.toString(prices));     // [0.0, 9.99, 0.0, 0.0]
        int sum = 0;
        for (int s : scores) sum += s;
        System.out.println("average " + sum / (double) scores.length);
    }
}
class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        Object o = a;                                     // arrays are Objects
        System.out.println(o instanceof int[]);           // true
        System.out.println(a.getClass().getSimpleName()); // int[]
        System.out.println(a.getClass().getName());       // [I
        System.out.println(new String[0].getClass().getName()); // [Ljava.lang.String;
        int[] b = a.clone();                              // inherited from Object
        System.out.println(a == b);                       // false
    }
}

Q2What are the default values of array elements?

Unlike local variables, array slots are always initialised. Numbers get 0, booleans get false, chars get '\u0000', and every reference slot gets null.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        System.out.println(Arrays.toString(new int[3]));      // [0, 0, 0]
        System.out.println(Arrays.toString(new double[2]));   // [0.0, 0.0]
        System.out.println(Arrays.toString(new boolean[2]));  // [false, false]
        System.out.println(Arrays.toString(new String[2]));   // [null, null]
        char[] cs = new char[2];
        System.out.println((int) cs[0]);                      // 0: the '\u0000' char
    }
}
import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] counts = new int[5];      // elements start at 0, so ++ just works
        for (int d : new int[]{1, 3, 3, 4, 1, 3}) counts[d]++;
        System.out.println(Arrays.toString(counts));   // [0, 2, 0, 3, 1]

        // A local int has no default: uncommenting the next line won't compile
        // int x; System.out.println(x);
        Arrays.fill(counts, -1);                      // pick your own default
        System.out.println(Arrays.toString(counts));
    }
}

Q3What does an array of objects actually store?

Addresses. A String[] doesn't contain any characters. Each slot points at a separate String object, or is null. Creating the array doesn't create a single String.

Try it: 2 runnable examples

class Main {
    static class Point { int x, y; Point(int x, int y) { this.x = x; this.y = y; } }

    public static void main(String[] args) {
        Point[] pts = new Point[3];        // 3 empty slots, no Point objects yet
        System.out.println(pts[0]);        // null
        pts[0] = new Point(1, 2);
        pts[1] = pts[0];                   // two slots, one object
        pts[1].x = 99;
        System.out.println(pts[0].x);      // 99
        try { System.out.println(pts[2].x); }
        catch (NullPointerException e) { System.out.println("pts[2] is null"); }
    }
}
class Main {
    public static void main(String[] args) {
        String hello = "hello";
        String[] words = {hello, hello, "hello"};
        System.out.println(words[0] == words[2]); // true: one pooled object, three references

        words[0] = "bye";                         // replaces a reference
        System.out.println(hello);                // hello: the String is untouched
        System.out.println(String.join(",", words));
    }
}

Q4Is an array passed by reference to a method?

No. Java always passes by value. For an array, the value being copied is the address. The method can change the elements through that address, but reassigning its parameter doesn't affect the caller's variable.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    static void doubleAll(int[] a) {
        for (int i = 0; i < a.length; i++) a[i] *= 2;   // writes through the copied address
    }
    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        doubleAll(nums);
        System.out.println(Arrays.toString(nums));      // [2, 4, 6]
    }
}
import java.util.Arrays;

class Main {
    static void replace(int[] a) {
        a = new int[]{9, 9, 9};       // only the local copy of the address moves
        a[0] = 0;
    }
    static int[] grow(int[] a) {
        return Arrays.copyOf(a, a.length + 1);   // return the new array instead
    }
    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        replace(nums);
        System.out.println(Arrays.toString(nums));   // [1, 2, 3]
        nums = grow(nums);
        System.out.println(Arrays.toString(nums));   // [1, 2, 3, 0]
    }
}

Copying, comparing and 2D arrays

Where most aliasing bugs come from.

Q5How do you copy an array?

b = a isn't a copy. It gives a second name to the same array. To get a real copy, create a new array.

MethodNew array?Use it when
a.clone()YesYou want an exact copy of the same length
Arrays.copyOf(a, n)YesYou want to grow or shrink. Extra slots get default values
Arrays.copyOfRange(a, from, to)YesYou want part of the array. to is exclusive
System.arraycopy(src, sp, dst, dp, len)No, fills an existing oneThe target already exists. Works even when the ranges overlap

All four are shallow. They copy the values in the slots, which for object arrays means copying addresses.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] src = {1, 2, 3, 4, 5};
        int[] a = src.clone();
        int[] b = Arrays.copyOf(src, 7);          // padded with zeros
        int[] c = Arrays.copyOfRange(src, 1, 4);  // [2, 3, 4]
        int[] d = new int[5];
        System.arraycopy(src, 0, d, 1, 4);        // shift right by one

        src[0] = 100;                             // copies don't change
        System.out.println(Arrays.toString(a));
        System.out.println(Arrays.toString(b));
        System.out.println(Arrays.toString(c));
        System.out.println(Arrays.toString(d));
    }
}
import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] original = {1, 2, 3};
        int[] alias = original;            // same array
        int[] copy = original.clone();     // new array
        alias[0] = 42;
        System.out.println(Arrays.toString(original)); // [42, 2, 3]
        System.out.println(Arrays.toString(copy));     // [1, 2, 3]

        // arraycopy handles overlapping ranges correctly
        System.arraycopy(original, 0, original, 1, 2);
        System.out.println(Arrays.toString(original)); // [42, 42, 2]
    }
}

Q6What is the difference between a shallow and a deep copy?

A 2D array is an array whose slots hold the addresses of row arrays. clone() copies the outer array only, so both copies share the rows. A deep copy clones every row as well.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[][] grid = {{1, 2}, {3, 4}};
        int[][] shallow = grid.clone();       // new outer array, same rows
        shallow[0][0] = 99;
        System.out.println(Arrays.deepToString(grid));   // [[99, 2], [3, 4]]
        System.out.println(grid[0] == shallow[0]);       // true: shared row
    }
}
import java.util.Arrays;

class Main {
    static int[][] deepCopy(int[][] src) {
        int[][] out = new int[src.length][];
        for (int i = 0; i < src.length; i++) out[i] = src[i].clone();
        return out;
    }
    public static void main(String[] args) {
        int[][] grid = {{1, 2}, {3, 4}};
        int[][] deep = deepCopy(grid);
        deep[0][0] = 99;
        System.out.println(Arrays.deepToString(grid));   // [[1, 2], [3, 4]]
        System.out.println(Arrays.deepToString(deep));   // [[99, 2], [3, 4]]
        System.out.println(grid[0] == deep[0]);          // false
    }
}

Q7What is a jagged array?

Because each row is a separate array, rows can have different lengths. new int[3][] creates only the outer array. new int[3][4] creates 4 objects: the outer array plus 3 rows.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int n = 6;
        int[][] tri = new int[n][];
        for (int r = 0; r < n; r++) {
            tri[r] = new int[r + 1];               // each row its own length
            tri[r][0] = tri[r][r] = 1;
            for (int c = 1; c < r; c++) tri[r][c] = tri[r - 1][c - 1] + tri[r - 1][c];
        }
        for (int[] row : tri) System.out.println(Arrays.toString(row));
    }
}
class Main {
    public static void main(String[] args) {
        String[][] teams = {
            {"Ada", "Linus"},
            {"Grace"},
            {"Ken", "Dennis", "Bjarne"},
        };
        for (int i = 0; i < teams.length; i++) {
            System.out.println("team " + i + " has " + teams[i].length + ": " + String.join(", ", teams[i]));
        }
        int[][] m = new int[2][];          // second size can be left out
        System.out.println(m[0]);          // null until you create the row
    }
}

Q8How do you compare two arrays?

Use Arrays.equals(a, b) for one-dimensional arrays and Arrays.deepEquals(a, b) for nested ones. Both == and a.equals(b) only check whether the two variables point at the same object.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3}, b = {1, 2, 3};
        System.out.println(a == b);               // false: different objects
        System.out.println(a.equals(b));          // false: Object.equals is ==
        System.out.println(Arrays.equals(a, b));  // true: compares elements
        System.out.println(Arrays.hashCode(a) == Arrays.hashCode(b)); // true
    }
}
import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[][] x = {{1, 2}, {3}};
        int[][] y = {{1, 2}, {3}};
        System.out.println(Arrays.equals(x, y));      // false: compares row references
        System.out.println(Arrays.deepEquals(x, y));  // true
        System.out.println(Arrays.compare(new int[]{1, 2}, new int[]{1, 3})); // negative
        System.out.println(Arrays.mismatch(new int[]{1, 2, 3}, new int[]{1, 2, 4})); // 2
    }
}

Internals and exceptions

Why arrays are fast, and what the JVM checks for you.

Q9Why is a[i] O(1), and why do indexes start at 0?

All elements are the same size and sit next to each other, so the JVM finds any element with one multiply and one add. Reading a[0] and a[999999] takes the same time. Index 0 sits right at the start of the element data, so no subtraction is needed. Change the type and index to see the calculation.

Element type

Assumes a 64-bit HotSpot JVM with compressed pointers, so a reference takes 4 bytes. The base address 0x7C10 is made up.

Try it: 2 runnable examples

class Main {
    public static void main(String[] args) {
        long base = 0x1000;          // pretend start of the element data
        int elementSize = 4;         // an int takes 4 bytes
        for (int i = 0; i < 5; i++) {
            long addr = base + (long) i * elementSize;   // one multiply, one add
            System.out.printf("a[%d] at 0x%X%n", i, addr);
        }
    }
}
class Main {
    public static void main(String[] args) {
        int[] big = new int[10_000_000];
        big[9_999_999] = 7;
        long t0 = System.nanoTime();
        long sum = 0;
        for (int rep = 0; rep < 1_000_000; rep++) sum += big[0] + big[9_999_999];
        long t1 = System.nanoTime();
        System.out.println("sum " + sum);
        System.out.printf("first and last element read 1,000,000 times each in %d ms%n", (t1 - t0) / 1_000_000);
    }
}

Q10When is ArrayIndexOutOfBoundsException thrown?

Valid indexes run from 0 to length - 1. The JVM checks every access, so reading past the end throws instead of returning random memory as C would. The classic cause is <= in a loop. A negative size in new int[-1] throws NegativeArraySizeException.

Try it: 2 runnable examples

class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30};
        try {
            for (int i = 0; i <= a.length; i++) {      // bug: should be <
                System.out.println(a[i]);
            }
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Caught: " + e.getMessage());
        }
    }
}
class Main {
    static int getOr(int[] a, int i, int fallback) {
        return (i >= 0 && i < a.length) ? a[i] : fallback;
    }
    public static void main(String[] args) {
        int[] a = {10, 20, 30};
        System.out.println(getOr(a, 1, -1));   // 20
        System.out.println(getOr(a, -1, -1));  // -1: Java has no negative indexing
        try { System.out.println(a[-1]); }
        catch (ArrayIndexOutOfBoundsException e) { System.out.println(e.getMessage()); }
        try { int[] bad = new int[-1]; }
        catch (NegativeArraySizeException e) { System.out.println("NegativeArraySizeException: " + e.getMessage()); }
    }
}

Q11What is ArrayStoreException?

Arrays are covariant: a String[] can be used where an Object[] is expected. That lets the compiler accept code that is wrong, so the JVM checks every store into an object array at run time. Generics avoid this by being invariant, which is also why new T[n] isn't allowed.

Try it: 2 runnable examples

class Main {
    public static void main(String[] args) {
        Object[] objs = new String[2];     // allowed: String[] is an Object[]
        objs[0] = "fine";
        try {
            objs[1] = Integer.valueOf(42);  // compiles, fails at run time
        } catch (ArrayStoreException e) {
            System.out.println("ArrayStoreException: " + e.getMessage());
        }
    }
}
import java.util.*;

class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
        // List<Object> objs = names;   // won't compile: generics are invariant
        List<? extends Object> view = names; // read-only view is fine
        names.add("Ada");
        System.out.println(view.get(0));

        Number[] nums = new Integer[1];
        try { nums[0] = 3.14; }             // Double into an Integer[]
        catch (ArrayStoreException e) { System.out.println("ArrayStoreException: " + e.getMessage()); }
    }
}

Q13Binary search

On a sorted array, check the middle and throw away the half that can't hold the target. This takes O(log n) steps, so 1 million elements need at most 20 checks. (lo + hi) >>> 1 avoids the overflow that (lo + hi) / 2 can hit on huge arrays.

The numbers are sorted for you, since binary search needs sorted input.

Try it: 2 runnable examples

class Main {
    static int search(int[] a, int target) {
        int lo = 0, hi = a.length - 1, steps = 0;
        while (lo <= hi) {
            int mid = (lo + hi) >>> 1;
            steps++;
            if (a[mid] == target) { System.out.println("steps: " + steps); return mid; }
            if (a[mid] < target) lo = mid + 1; else hi = mid - 1;
        }
        System.out.println("steps: " + steps);
        return -(lo + 1);                     // same convention as Arrays.binarySearch
    }
    public static void main(String[] args) {
        int[] a = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91};
        System.out.println(search(a, 23));    // 5
        System.out.println(search(a, 7));     // -3: would insert at index 2
    }
}
import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] a = {91, 2, 56, 8, 23};
        Arrays.sort(a);                                 // must be sorted first
        System.out.println(Arrays.toString(a));
        System.out.println(Arrays.binarySearch(a, 23)); // 2
        int r = Arrays.binarySearch(a, 50);
        System.out.println(r + " -> insert at " + (-r - 1));
        int n = 1_000_000;
        System.out.println("max checks for 1M: " + (32 - Integer.numberOfLeadingZeros(n)));
    }
}

Q14Bubble sort

Compare neighbours and swap them when they're out of order. Each pass moves the largest remaining value to the end. It takes O(n²) time, but stopping when a pass makes no swaps makes it O(n) on sorted input. Up to 8 numbers.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    static void bubble(int[] a) {
        for (int pass = 0; pass < a.length - 1; pass++) {
            boolean swapped = false;
            for (int i = 0; i < a.length - 1 - pass; i++) {
                if (a[i] > a[i + 1]) { int t = a[i]; a[i] = a[i + 1]; a[i + 1] = t; swapped = true; }
            }
            System.out.println("pass " + (pass + 1) + ": " + Arrays.toString(a));
            if (!swapped) break;
        }
    }
    public static void main(String[] args) {
        bubble(new int[]{5, 1, 4, 2, 8});
    }
}
class Main {
    static int comparisons(int[] a) {
        int count = 0;
        for (int pass = 0; pass < a.length - 1; pass++) {
            boolean swapped = false;
            for (int i = 0; i < a.length - 1 - pass; i++) {
                count++;
                if (a[i] > a[i + 1]) { int t = a[i]; a[i] = a[i + 1]; a[i + 1] = t; swapped = true; }
            }
            if (!swapped) break;
        }
        return count;
    }
    public static void main(String[] args) {
        int n = 100;
        int[] sorted = new int[n], reversed = new int[n];
        for (int i = 0; i < n; i++) { sorted[i] = i; reversed[i] = n - i; }
        System.out.println("sorted:   " + comparisons(sorted));    // n - 1
        System.out.println("reversed: " + comparisons(reversed));  // n(n-1)/2
    }
}

Q15Maximum subarray sum (Kadane's algorithm)

At each element, decide whether to extend the current run or start a new one there. Track the best sum seen so far. One pass gives O(n) time and O(1) extra space.

Try it: 2 runnable examples

import java.util.Arrays;

class Main {
    public static void main(String[] args) {
        int[] a = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
        int cur = a[0], best = a[0], start = 0, bestL = 0, bestR = 0;
        for (int i = 1; i < a.length; i++) {
            if (a[i] > cur + a[i]) { cur = a[i]; start = i; }   // start fresh
            else cur += a[i];                                   // extend
            if (cur > best) { best = cur; bestL = start; bestR = i; }
        }
        System.out.println("best sum " + best);
        System.out.println(Arrays.toString(Arrays.copyOfRange(a, bestL, bestR + 1)));
    }
}
class Main {
    static int maxSub(int[] a) {
        int cur = a[0], best = a[0];
        for (int i = 1; i < a.length; i++) {
            cur = Math.max(a[i], cur + a[i]);
            best = Math.max(best, cur);
        }
        return best;
    }
    public static void main(String[] args) {
        System.out.println(maxSub(new int[]{-8, -3, -6, -2, -5}));  // -2: the least negative
        System.out.println(maxSub(new int[]{5, -9, 6, -2, 3}));     // 7
    }
}

Q16Two Sum on a sorted array

Put one pointer at each end. If the sum is too small, move the left pointer right. If it's too big, move the right pointer left. This takes O(n) time with no extra memory. For unsorted input, a HashMap gives O(n) time instead.

Try it: 2 runnable examples

class Main {
    public static void main(String[] args) {
        int[] a = {1, 3, 4, 6, 8, 11};
        int target = 10, lo = 0, hi = a.length - 1;
        while (lo < hi) {
            int sum = a[lo] + a[hi];
            System.out.println("a[" + lo + "] + a[" + hi + "] = " + sum);
            if (sum == target) { System.out.println("found " + a[lo] + " + " + a[hi]); return; }
            if (sum < target) lo++; else hi--;
        }
        System.out.println("no pair");
    }
}
import java.util.*;

class Main {
    static int[] twoSum(int[] a, int target) {
        Map<Integer, Integer> seen = new HashMap<>();   // value -> index
        for (int i = 0; i < a.length; i++) {
            Integer j = seen.get(target - a[i]);
            if (j != null) return new int[]{j, i};
            seen.put(a[i], i);
        }
        return new int[0];
    }
    public static void main(String[] args) {
        System.out.println(Arrays.toString(twoSum(new int[]{8, 3, 11, 1, 6}, 9)));  // [0, 3]
        System.out.println(Arrays.toString(twoSum(new int[]{2, 4}, 100)));        // []
    }
}

Quick answers

length, length() or size()?
Arrays have a length field. Strings have length(). Collections have size().
Can an array change size?
No. Make a bigger one with Arrays.copyOf, or use an ArrayList.
How do I print an array?
Arrays.toString(a), or Arrays.deepToString(m) for 2D arrays.
What does Arrays.sort use?
Dual-Pivot Quicksort for primitives. TimSort for objects, which is stable.
What does Arrays.asList return?
A fixed-size list backed by the array. set() writes through to it, and add() throws UnsupportedOperationException.
What is the largest possible array?
Indexes are int, so just under 231 − 1 elements, if the heap is big enough.
int[] a, b or int a[], b?
In the first, both are arrays. In the second, b is a plain int.
What are varargs?
int... nums is an int[] inside the method. Callers can pass values or an array.
Can I create new T[n]?
No, because generic types are erased at run time. Use (T[]) new Object[n] or Array.newInstance.
Are arrays thread-safe?
No. Use locks, or AtomicIntegerArray for counters shared between threads.
Addresses such as @3f2a are made up for illustration. Sizes assume a 64-bit HotSpot JVM with compressed pointers. Companion page: Inside java.lang.String
