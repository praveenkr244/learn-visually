Getting started

Python is a readable, general-purpose language used for web apps, automation, data science, AI, scripting and teaching. You write plain text files ending in .py and the Python interpreter runs them.

Install and run

  1. Download Python 3.12 or newer from python.org (on Windows tick “Add python.exe to PATH”). macOS: brew install python. Linux usually ships with it.
  2. Check it works: open a terminal and type python --version (or python3 --version).
  3. Type python alone to get the interactive REPL (the >>> prompt). Great for trying one-liners. Exit with exit().
  4. Save code in hello.py and run python hello.py.
  5. Use an editor with Python support: VS Code (with the Python extension) or PyCharm.

Python is case-sensitive (Name ≠ name). A colon : starts a block and the indented lines below belong to it. Use 4 spaces, never mix tabs and spaces. One statement per line; long expressions can continue inside brackets.

Conditions: if, elif, else

Python checks each condition from top to bottom and runs the first block whose condition is true. The rest are skipped.

temp = 22
if temp > 30:
    print("hot")
elif temp > 15:
    print("pleasant")
else:
    print("cold")

# Conditional expression (ternary)
label = "even" if temp % 2 == 0 else "odd"
print(label)

# Truthiness: empty/zero values count as False
for value in [0, 1, "", "x", [], [0], None, {}]:
    print(repr(value), "->", "truthy" if value else "falsy")
Falsy values (everything else is truthy)
False, None, 0, 0.0, "", [], (), {}, set(), range(0)

Prefer if items: over if len(items) > 0:, and if x is None: over if x == None:. For many fixed cases, see match statements.

Loops: for and while

for walks through every item of an iterable (list, string, range, dict, file…). while repeats as long as a condition stays true.

for i in range(5):            # 0 1 2 3 4
    print(i, end=" ")
print()
print(list(range(2, 10, 3)))  # start, stop (excluded), step → [2, 5, 8]

# enumerate gives index + item; zip walks lists in parallel
fruits = ["apple", "banana", "cherry"]
prices = [1.2, 0.5, 3.0]
for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)
for fruit, price in zip(fruits, prices):
    print(f"{fruit:8} ${price:.2f}")

# while: repeat until a condition changes
n = 10
while n > 1:
    n = n // 2
    print("n is", n)

# break exits the loop; continue skips to the next round
for x in range(10):
    if x % 2 == 0:
        continue
    if x > 7:
        break
    print("odd:", x)

# for/else: else runs only if the loop did NOT break
for x in [3, 5, 7]:
    if x % 2 == 0:
        print("found an even"); break
else:
    print("no even numbers")
Avoid infinite loops

Make sure something inside a while loop moves it toward ending. Press Ctrl+C in the terminal to stop a runaway program. Don't add or remove items from a list while looping over it; loop over a copy (for x in items[:]) or build a new list.

Sets

A set is an unordered collection of unique items. It's perfect for removing duplicates and for fast “is this in there?” checks, and supports math-style operations.

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a | b, a & b, a - b, a ^ b)
print(a.issubset({1, 2, 3, 4, 5}), {1, 2} <= a)

tags = ["py", "web", "py", "ai", "web"]

print(unique, len(unique))
unique.add("data"); unique.discard("web")

empty = set()        # {} is an empty DICT, not a set
print(type({}), type(empty))

Membership tests (x in s) are O(1) on average for sets and dicts but O(n) for lists. If you check membership in a loop, convert the list to a set first.

Functions and the call stack

A function is a named, reusable block of code. You define it once with def and call it as many times as you like. Each call gets its own frame on the call stack holding its local variables.

def greet(name, greeting="Hello"):
    """Return a greeting. (This is a docstring: help(greet) shows it.)"""
    return f"{greeting}, {name}!"

print(greet("Ada"))                     # default used
print(greet("Linus", greeting="Hi"))    # keyword argument
print(greet(greeting="Hey", name="Guido"))

def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

low, high, avg = stats([3, 9, 6])       # returning several values = a tuple
print(low, high, avg)

def say():
    print("no return statement")
print(say())                            # functions return None by default
The mutable default trap

Default values are created once, when the function is defined. def add(item, bucket=[]) shares one list across all calls. Use bucket=None and create the list inside. See mutability.

Scope: where names live (LEGB)

When Python sees a name, it searches four scopes in order: Local → Enclosing function → Global (module) → Built-in. The first match wins.

x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print("inner sees:", x)
    inner()
    print("outer sees:", x)

outer()
print("module sees:", x)

counter = 0
def bump():
    global counter       # needed to REASSIGN a global
    counter += 1
bump(); bump()
print(counter)

def make_counter():
    count = 0
    def step():
        nonlocal count   # reassign the enclosing variable
        count += 1
        return count
    return step
c = make_counter()
print(c(), c(), c())

Reading an outer variable needs nothing special. Only reassigning it needs global or nonlocal. Prefer passing values in and returning them out over using globals.

Errors and exceptions

When something goes wrong, Python raises an exception. If nobody catches it, the program stops and prints a traceback. try/except lets you catch and handle it.

def parse_age(text):
    if not text.isdigit():
        raise ValueError(f"not a number: {text!r}")
    return int(text)

for raw in ["42", "forty"]:
    try:
        print("age:", parse_age(raw))
    except ValueError as err:
        print("problem:", err)

# Custom exceptions: subclass Exception
class InsufficientFunds(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFunds(f"need {amount - balance} more")
    return balance - amount

try:
    withdraw(50, 80)
except InsufficientFunds as e:
    print("Declined:", e)

# Catch several types at once
try:
    {}["missing"]
except (KeyError, IndexError) as e:
    print(type(e).__name__, e)

Decorators

A decorator is a function that takes a function and returns a new one that wraps it. @timer above def f means f = timer(f). Use them to add logging, timing, caching, access checks or retries without touching the function's body.

import functools, time

def timer(func):
    @functools.wraps(func)                # keep the name and docstring
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} took {time.perf_counter() - start:.4f}s")
        return result
    return wrapper

def log(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"calling {func.__name__}{args}")
        return func(*args, **kwargs)
    return wrapper

@timer
@log                     # applied bottom-up: greet = timer(log(greet))
def greet(name):
    return f"Hello {name}"
print(greet("Ada"))

def retry(times):        # a decorator that takes arguments = one more layer
    def decorate(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except ValueError as e:
                    print(f"attempt {attempt} failed: {e}")
            raise RuntimeError("all retries failed")
        return wrapper
    return decorate

calls = {"n": 0}
@retry(times=3)
def flaky():
    calls["n"] += 1
    if calls["n"] < 3:
        raise ValueError("not yet")
    return "success"
print(flaky())

Most surprising Python bugs come from two names sharing one mutable object. Know when you're copying and when you're just adding another name tag.

import copy

print("shallow", shallow)         # sees 99 too!
print("deep   ", deep)            # unaffected

def add_bad(item, bucket=[]):
    bucket.append(item); return bucket
print(add_bad(1), add_bad(2))     # [1, 2] [1, 2]  shared!

def add_good(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item); return bucket
print(add_good(1), add_good(2))   # [1] [2]

def clear_it(lst): lst.clear()
data = [1, 2, 3]; clear_it(data); print(data)

Async and await

asyncio runs many tasks on one thread. When a task waits for I/O (network, disk, a timer) it awaits and hands control back to the event loop, which runs another task. Waits overlap, so total time drops.

import asyncio, time

async def download(name, seconds):
    print(f"start {name}")
    await asyncio.sleep(seconds)      # pretend network wait; yields to the loop
    print(f"done  {name}")
    return name, seconds

async def main():
    start = time.perf_counter()
    results = await asyncio.gather(   # run concurrently
        download("A", 2), download("B", 1), download("C", 3)
    )
    print(results, f"{time.perf_counter() - start:.1f}s")   # ~3.0s, not 6.0s

    # Structured concurrency (3.11+)
    async with asyncio.TaskGroup() as tg:
        t1 = tg.create_task(download("D", 1))
        t2 = tg.create_task(download("E", 1))
    print(t1.result(), t2.result())

    try:                               # timeouts
        async with asyncio.timeout(0.5):
            await download("slow", 5)
    except TimeoutError:
        print("gave up on slow")

asyncio.run(main())                   # start the event loop
Rules of async

Only call await inside async def. Never call blocking code (time.sleep, requests.get) inside a coroutine; it freezes the whole loop. Use async libraries (httpx, aiohttp, asyncpg) or await asyncio.to_thread(blocking_fn).

class Positive:
    """A descriptor: controls attribute access on another class."""
    def __set_name__(self, owner, name):
        self.name = "_" + name
    def __get__(self, obj, objtype=None):
        return getattr(obj, self.name)
    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.name[1:]} must be positive")
        setattr(obj, self.name, value)

class Product:
    price = Positive()
    qty = Positive()
    def __init__(self, price, qty):
        self.price, self.qty = price, qty

p = Product(9.5, 2)
try:
    p.qty = 0
except ValueError as e:
    print(e)

class Registry(type):                 # a metaclass: a class that makes classes
    plugins = {}
    def __new__(mcls, name, bases, ns):
        cls = super().__new__(mcls, name, bases, ns)
        if bases:
            mcls.plugins[name.lower()] = cls
        return cls
